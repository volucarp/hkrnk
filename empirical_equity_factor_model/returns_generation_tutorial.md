# Tutorial: Generating Stock Returns from an Eight-Factor Risk Model

## What we are building

We want to simulate \(T=251\) days of returns for \(N\) stocks. The returns should look as though they were generated by an eight-factor equity risk model:

$$
r_t=\mu+Bf_t+\epsilon_t.
$$

The terms are:

- \(r_t\in\mathbb{R}^N\): stock returns on day \(t\);
- \(\mu\in\mathbb{R}^N\): expected daily stock returns;
- \(B\in\mathbb{R}^{N\times8}\): stock exposures to the eight factors;
- \(f_t\in\mathbb{R}^8\): factor returns on day \(t\); and
- \(\epsilon_t\in\mathbb{R}^N\): stock-specific returns on day \(t\).

The factors create correlated stock returns. The specific shocks add independent variation to each stock.

The model-implied stock covariance matrix is:

$$
\boxed{
\Sigma=BV_fB^\top+\Delta,
}
$$

where \(V_f\) is the factor covariance matrix and \(\Delta\) is the diagonal matrix of specific variances.

## 1. The main idea

Start with two sets of independent standard-normal random numbers:

1. eight random factor shocks per day; and
2. one random specific shock per stock per day.

Transform the factor shocks to give them the desired factor covariance. Next, map those factor returns into stock space using the exposure matrix \(B\). Finally, add independently scaled specific shocks.

The complete matrix equation is:

$$
\boxed{
R
=
\mathbf{1}_T\mu^\top
+
FB^\top
+
ZD_\epsilon.
}
$$

The dimensions are:

| Variable | Shape | Meaning |
| --- | ---: | --- |
| \(R\) | \(T\times N\) | Simulated stock returns |
| \(F\) | \(T\times8\) | Simulated factor returns |
| \(B\) | \(N\times8\) | Stock factor exposures |
| \(Z\) | \(T\times N\) | Independent standard-normal specific shocks |
| \(D_\epsilon\) | \(N\times N\) | Diagonal specific-volatility matrix |
| \(\mu\) | \(N\times1\) | Expected daily stock returns |

Every matrix multiplication in the equation has shape \(T\times N\).

## 2. Set the simulation dimensions

This tutorial uses:

```python
import numpy as np

seed = 7
T = 251
N = 500
K = 8
trading_days = 251

rng = np.random.default_rng(seed)
```

Using one random generator makes the entire simulation reproducible.

## 3. Define expected stock returns

Suppose every stock has an expected annual arithmetic return of 8%:

$$
\mu_i^{(a)}=0.08.
$$

Convert annual expected returns to daily expected returns:

$$
\mu_i=\frac{\mu_i^{(a)}}{251}.
$$

In NumPy:

```python
annual_mean = np.full(N, 0.08)
mu = annual_mean / trading_days
```

The mean component of the full return matrix is:

$$
\mathbf{1}_T\mu^\top
\in\mathbb{R}^{T\times N}.
$$

## 4. Define the eight factors

The factors can represent:

1. market;
2. size;
3. value;
4. momentum;
5. quality;
6. low volatility;
7. liquidity; and
8. growth.

These names are interpretations. Mathematically, the generator only needs eight random return series and an exposure to each series for every stock.

### 4.1 Choose factor volatilities

Choose annualized factor volatilities:

```python
factor_annual_vol = np.array(
    [0.18, 0.10, 0.09, 0.12, 0.08, 0.08, 0.07, 0.09]
)
```

Convert them to daily volatilities:

$$
s_f=\frac{s_f^{(a)}}{\sqrt{251}}.
$$

```python
factor_daily_vol = factor_annual_vol / np.sqrt(trading_days)
```

### 4.2 Choose factor correlations

The simplest starting point uses independent factors:

$$
C_f=I_8.
$$

```python
factor_correlation = np.eye(K)
```

A dense positive-semidefinite factor correlation matrix can be used later. The daily factor covariance is:

$$
V_f
=
\operatorname{Diag}(s_f)
C_f
\operatorname{Diag}(s_f).
$$

```python
factor_vol_matrix = np.diag(factor_daily_vol)
V_f = (
    factor_vol_matrix
    @ factor_correlation
    @ factor_vol_matrix
)
```

## 5. Generate correlated factor returns

Start with independent standard-normal source shocks:

$$
U_{t,k}\overset{\text{iid}}{\sim}\mathcal{N}(0,1),
\qquad
U\in\mathbb{R}^{T\times8}.
$$

```python
U = rng.standard_normal((T, K))
```

Compute a Cholesky factor:

$$
A_fA_f^\top=V_f.
$$

```python
A_f = np.linalg.cholesky(V_f)
```

Transform the independent shocks:

$$
F=UA_f^\top.
$$

```python
F = U @ A_f.T
```

Each row of \(F\) is now an eight-dimensional factor-return vector:

$$
f_t\sim\mathcal{N}(0,V_f).
$$

The covariance proof is:

$$
\begin{aligned}
\operatorname{Cov}(f_t)
&=
A_f\operatorname{Cov}(u_t)A_f^\top\\
&=
A_fI_8A_f^\top\\
&=
V_f.
\end{aligned}
$$

The Cholesky matrix stretches and mixes the original independent shocks so they have the specified factor volatilities and correlations.

## 6. Create stock factor exposures

The exposure matrix is:

$$
B_0\in\mathbb{R}^{N\times8}.
$$

Row \(i\) contains the eight exposures of stock \(i\).

### 6.1 Market exposures

Market betas are generally positive and centered near one:

```python
market_beta = np.clip(
    rng.normal(loc=1.0, scale=0.15, size=N),
    0.4,
    1.6,
)
```

### 6.2 Style exposures

Style exposures can be positive or negative and centered near zero:

```python
style_exposures = rng.normal(
    loc=0.0,
    scale=0.35,
    size=(N, K - 1),
)
```

Combine them:

```python
B0 = np.column_stack([market_beta, style_exposures])
```

Thus:

$$
B_0
=
\begin{bmatrix}
b_{1,1} & \cdots & b_{1,8}\\
\vdots & \ddots & \vdots\\
b_{N,1} & \cdots & b_{N,8}
\end{bmatrix}.
$$

The positive first column creates broad market co-movement. The mixed-sign style columns create heterogeneous pairwise correlations.

## 7. Define specific risk

Choose an annualized specific volatility for every stock:

```python
specific_annual_vol = rng.uniform(0.18, 0.35, size=N)
specific_daily_vol = (
    specific_annual_vol / np.sqrt(trading_days)
)
specific_variance = specific_daily_vol**2
```

Define:

$$
D_\epsilon
=
\operatorname{Diag}
\left(
\sqrt{d_\epsilon}
\right)
=
\operatorname{Diag}(s_\epsilon),
$$

and:

$$
\Delta
=
D_\epsilon^2
=
\operatorname{Diag}(d_\epsilon).
$$

Here:

- \(s_\epsilon\) is the vector of daily specific volatilities; and
- \(d_\epsilon=s_\epsilon\odot s_\epsilon\) is the vector of daily specific variances.

## 8. Understand how the model creates stock correlation

The systematic return of stock \(i\) is:

$$
b_i^\top f_t.
$$

For two different stocks:

$$
\operatorname{Cov}(r_{t,i},r_{t,j})
=
b_i^\top V_fb_j.
$$

Their specific shocks do not contribute because specific returns are independent across stocks.

The total variance of stock \(i\) is:

$$
\sigma_i^2
=
b_i^\top V_fb_i+d_{\epsilon,i}.
$$

Therefore:

$$
\boxed{
\operatorname{Corr}(r_{t,i},r_{t,j})
=
\frac{
b_i^\top V_fb_j
}{
\sqrt{
\left(b_i^\top V_fb_i+d_{\epsilon,i}\right)
\left(b_j^\top V_fb_j+d_{\epsilon,j}\right)
}
}.
}
$$

The model creates larger correlations when stocks have similar factor exposures. Increasing specific risk lowers correlations because more of each stock's movement becomes independent.

## 9. Calibrate average correlation to 0.30

The raw exposure matrix \(B_0\) does not automatically produce an average correlation of 0.30. Introduce a systematic-risk scale:

$$
B(\gamma)=\gamma B_0,
\qquad
\gamma\geq0.
$$

Increasing \(\gamma\) strengthens common factor risk relative to specific risk.

For a candidate \(\gamma\):

$$
\Sigma(\gamma)
=
\gamma^2B_0V_fB_0^\top+\Delta.
$$

We can calculate its average correlation efficiently without constructing the full \(N\times N\) correlation matrix.

### 9.1 Standardized factor loadings

First factor the common covariance:

$$
B_0V_fB_0^\top
=
(B_0A_f)(B_0A_f)^\top.
$$

Define:

$$
L_0=B_0A_f
\in\mathbb{R}^{N\times8}.
$$

At scale \(\gamma\), stock \(i\)'s total variance is:

$$
v_i(\gamma)
=
\gamma^2\lVert L_{0,i}\rVert_2^2
+
d_{\epsilon,i}.
$$

Its standardized factor-loading row is:

$$
H_i(\gamma)
=
\frac{\gamma L_{0,i}}{\sqrt{v_i(\gamma)}}.
$$

The off-diagonal stock correlations are the off-diagonal entries of:

$$
H(\gamma)H(\gamma)^\top.
$$

The sum of all entries in this matrix is:

$$
\mathbf{1}_N^\top
H(\gamma)H(\gamma)^\top
\mathbf{1}_N
=
\left\lVert
H(\gamma)^\top\mathbf{1}_N
\right\rVert_2^2.
$$

Subtracting the diagonal gives the sum of off-diagonal correlations:

$$
\sum_{i\neq j}C_{ij}(\gamma)
=
\left\lVert
\sum_{i=1}^N H_i(\gamma)
\right\rVert_2^2
-
\sum_{i=1}^N
\lVert H_i(\gamma)\rVert_2^2.
$$

Therefore:

$$
\boxed{
\bar{\rho}(\gamma)
=
\frac{
\left\lVert\sum_iH_i(\gamma)\right\rVert_2^2
-\sum_i\lVert H_i(\gamma)\rVert_2^2
}{
N(N-1)
}.
}
$$

This calculation costs \(O(NK)\), rather than \(O(N^2)\).

### 9.2 Implement the average-correlation function

```python
L0 = B0 @ A_f
common_variance0 = np.sum(L0**2, axis=1)


def population_average_correlation(
    gamma: float,
) -> float:
    total_variance = (
        gamma**2 * common_variance0
        + specific_variance
    )
    H = (
        gamma * L0
        / np.sqrt(total_variance)[:, None]
    )

    sum_all = np.sum(np.sum(H, axis=0) ** 2)
    sum_diagonal = np.sum(H**2)

    return float(
        (sum_all - sum_diagonal)
        / (N * (N - 1))
    )
```

### 9.3 Search for the systematic-risk scale

Use a logarithmic grid to find a bracket around the target, then refine the bracket by bisection:

```python
target_correlation = 0.30
gamma_grid = np.geomspace(1e-3, 1e3, 2_000)

average_correlations = np.array(
    [
        population_average_correlation(gamma)
        for gamma in gamma_grid
    ]
)

differences = average_correlations - target_correlation
crossings = np.flatnonzero(
    differences[:-1] * differences[1:] <= 0.0
)

if crossings.size:
    index = crossings[0]
    lower = gamma_grid[index]
    upper = gamma_grid[index + 1]
    lower_error = differences[index]

    for _ in range(60):
        midpoint = np.sqrt(lower * upper)
        midpoint_error = (
            population_average_correlation(midpoint)
            - target_correlation
        )
        if lower_error * midpoint_error <= 0.0:
            upper = midpoint
        else:
            lower = midpoint
            lower_error = midpoint_error

    gamma = np.sqrt(lower * upper)
else:
    best_index = np.argmin(np.abs(differences))
    gamma = gamma_grid[best_index]

B = gamma * B0
population_average_corr = (
    population_average_correlation(gamma)
)
```

Always report the achieved population value:

```python
print(f"gamma: {gamma:.6f}")
print(
    "population average correlation: "
    f"{population_average_corr:.6f}"
)
```

A target may be unattainable for an arbitrary exposure design. Positive market exposures make a positive target such as 0.30 much more likely to be attainable.

## 10. Generate specific shocks

Generate:

$$
Z_{t,i}\overset{\text{iid}}{\sim}\mathcal{N}(0,1),
\qquad
Z\in\mathbb{R}^{T\times N},
$$

independently of the factor source shocks \(U\):

```python
Z = rng.standard_normal((T, N))
specific_returns = Z * specific_daily_vol[None, :]
```

This is equivalent to:

$$
E_\epsilon=ZD_\epsilon.
$$

Its covariance is:

$$
\operatorname{Cov}(\epsilon_t)=\Delta.
$$

## 11. Generate stock returns

Map the eight factor returns into the \(N\)-stock space:

$$
R_{\mathrm{factor}}=FB^\top
\in\mathbb{R}^{T\times N}.
$$

```python
factor_component = F @ B.T
```

Add the expected and specific returns:

$$
\boxed{
R
=
\mathbf{1}_T\mu^\top
+
FB^\top
+
ZD_\epsilon.
}
$$

```python
R = (
    mu[None, :]
    + factor_component
    + specific_returns
)
```

The population covariance is:

$$
\boxed{
\Sigma=BV_fB^\top+\Delta.
}
$$

The first term has rank no greater than eight, while the second term is diagonal.

## 12. Why these returns look factor-generated

On each day, every stock observes the same eight factor returns. Stocks react differently because their exposure rows \(b_i^\top\) differ.

For example, two stocks with similar market and value exposures receive similar systematic returns:

$$
b_i^\top f_t
\approx
b_j^\top f_t.
$$

Two stocks with opposite momentum exposures can move differently when the momentum factor has a large realization.

Specific shocks blur these relationships. As specific volatility increases, it becomes harder to infer the underlying exposures from only 251 observations.

The returns are therefore not merely given an arbitrary covariance matrix. They are generated through an explicit economic structure:

$$
\text{factor shocks}
\longrightarrow
\text{factor returns}
\longrightarrow
\text{stock systematic returns}
\longrightarrow
\text{stock returns plus specific noise}.
$$

## 13. Validate the generated sample

### 13.1 Basic checks

```python
assert R.shape == (T, N)
assert F.shape == (T, K)
assert B.shape == (N, K)
assert np.isfinite(R).all()
assert np.isfinite(F).all()
assert np.all(specific_variance > 0.0)
```

### 13.2 Population covariance

```python
Delta = np.diag(specific_variance)
Sigma = B @ V_f @ B.T + Delta

assert np.allclose(Sigma, Sigma.T)
assert np.linalg.eigvalsh(Sigma).min() > -1e-12
```

### 13.3 Realized sample average correlation

```python
sample_correlation = np.corrcoef(R, rowvar=False)
off_diagonal = ~np.eye(N, dtype=bool)
sample_average_corr = sample_correlation[off_diagonal].mean()

print(
    "target population average correlation: "
    f"{target_correlation:.6f}"
)
print(
    "calibrated population average correlation: "
    f"{population_average_corr:.6f}"
)
print(
    "251-day sample average correlation: "
    f"{sample_average_corr:.6f}"
)
```

The 251-day sample average will not equal 0.30 exactly. The generator targets the population correlation; the sample estimate fluctuates because it is calculated from only 251 random observations.

## 14. Check whether regression recovers the exposures

If the returns were generated by:

$$
R=\mathbf{1}_T\mu^\top+FB^\top+E_\epsilon,
$$

then regressing each stock's returns on the observed factor returns should approximately recover \(B\).

Fit every stock simultaneously:

```python
design = np.column_stack([np.ones(T), F])
coefficients = np.linalg.lstsq(
    design,
    R,
    rcond=None,
)[0]

alpha_hat = coefficients[0]
B_hat = coefficients[1:].T
```

Here:

$$
B_{\mathrm{hat}}\in\mathbb{R}^{N\times8}.
$$

Compare estimated and true exposures:

```python
exposure_rmse = np.sqrt(np.mean((B_hat - B) ** 2))
print(f"exposure RMSE: {exposure_rmse:.6f}")
```

The estimates will not match perfectly because of specific noise and the short sample. They should improve when:

- \(T\) increases;
- specific volatility decreases; or
- factor volatility increases relative to specific volatility.

This regression check is the practical meaning of saying that the returns likely came from the eight-factor model.

## 15. Complete example

```python
import numpy as np

# Dimensions and random generator
seed = 7
T = 251
N = 500
K = 8
trading_days = 251
rng = np.random.default_rng(seed)

# Expected daily stock returns
annual_mean = np.full(N, 0.08)
mu = annual_mean / trading_days

# Daily factor covariance
factor_annual_vol = np.array(
    [0.18, 0.10, 0.09, 0.12, 0.08, 0.08, 0.07, 0.09]
)
factor_daily_vol = factor_annual_vol / np.sqrt(trading_days)
factor_correlation = np.eye(K)
factor_vol_matrix = np.diag(factor_daily_vol)
V_f = (
    factor_vol_matrix
    @ factor_correlation
    @ factor_vol_matrix
)

# Factor returns
U = rng.standard_normal((T, K))
A_f = np.linalg.cholesky(V_f)
F = U @ A_f.T

# Unscaled stock exposures
market_beta = np.clip(
    rng.normal(1.0, 0.15, size=N),
    0.4,
    1.6,
)
style_exposures = rng.normal(
    0.0,
    0.35,
    size=(N, K - 1),
)
B0 = np.column_stack([market_beta, style_exposures])

# Specific risk
specific_annual_vol = rng.uniform(0.18, 0.35, size=N)
specific_daily_vol = specific_annual_vol / np.sqrt(trading_days)
specific_variance = specific_daily_vol**2

# Population average-correlation function
L0 = B0 @ A_f
common_variance0 = np.sum(L0**2, axis=1)


def population_average_correlation(
    gamma: float,
) -> float:
    total_variance = (
        gamma**2 * common_variance0
        + specific_variance
    )
    H = (
        gamma * L0
        / np.sqrt(total_variance)[:, None]
    )
    sum_all = np.sum(np.sum(H, axis=0) ** 2)
    sum_diagonal = np.sum(H**2)
    return float(
        (sum_all - sum_diagonal)
        / (N * (N - 1))
    )


# Calibrate systematic risk
target_correlation = 0.30
gamma_grid = np.geomspace(1e-3, 1e3, 2_000)
average_correlations = np.array(
    [
        population_average_correlation(gamma_value)
        for gamma_value in gamma_grid
    ]
)
differences = average_correlations - target_correlation
crossings = np.flatnonzero(
    differences[:-1] * differences[1:] <= 0.0
)

if crossings.size:
    index = crossings[0]
    lower = gamma_grid[index]
    upper = gamma_grid[index + 1]
    lower_error = differences[index]

    for _ in range(60):
        midpoint = np.sqrt(lower * upper)
        midpoint_error = (
            population_average_correlation(midpoint)
            - target_correlation
        )
        if lower_error * midpoint_error <= 0.0:
            upper = midpoint
        else:
            lower = midpoint
            lower_error = midpoint_error

    gamma = np.sqrt(lower * upper)
else:
    best_index = np.argmin(np.abs(differences))
    gamma = gamma_grid[best_index]

B = gamma * B0
population_average_corr = (
    population_average_correlation(gamma)
)

# Stock returns
Z = rng.standard_normal((T, N))
specific_returns = Z * specific_daily_vol[None, :]
R = mu[None, :] + F @ B.T + specific_returns

# Sample diagnostics
sample_correlation = np.corrcoef(R, rowvar=False)
off_diagonal = ~np.eye(N, dtype=bool)
sample_average_corr = sample_correlation[off_diagonal].mean()

print(f"returns shape: {R.shape}")
print(f"factor returns shape: {F.shape}")
print(f"exposure shape: {B.shape}")
print(f"gamma: {gamma:.6f}")
print(
    "population average correlation: "
    f"{population_average_corr:.6f}"
)
print(
    "sample average correlation: "
    f"{sample_average_corr:.6f}"
)
```

## 16. Summary

The generation strategy is:

$$
\boxed{
\begin{aligned}
U_{t,k}
&\overset{\text{iid}}{\sim}\mathcal{N}(0,1),\\
A_fA_f^\top
&=V_f,\\
F
&=UA_f^\top,\\
B
&=\gamma B_0,\\
Z_{t,i}
&\overset{\text{iid}}{\sim}\mathcal{N}(0,1),\\
\Delta
&=\operatorname{Diag}(d_\epsilon),\\
R
&=\mathbf{1}_T\mu^\top
+FB^\top
+ZD_\epsilon,\\
\operatorname{Cov}(r_t)
&=BV_fB^\top+\Delta.
\end{aligned}
}
$$

Independent random numbers become stock returns through two structured linear transformations:

1. \(A_f\) turns independent factor shocks into correlated factor returns.
2. \(B\) maps the eight factor returns into the \(N\)-stock return space.

The diagonal specific-risk term then adds variation that is unique to each security.
